# Test Portal — Architecture Context

This folder contains the core architecture and engineering context for the Test Portal project.

Purpose:

- help AI agents understand the project
- maintain scalable architecture
- avoid bad refactors
- preserve clean engineering structure
- standardize development rules

This project is a professional assessment platform built using:

- Next.js App Router
- React
- TypeScript

Main systems:

- Admin Portal
- Candidate Portal
- Assessment Engine
- Security Engine
- Realtime Engine

Before implementing ANY feature or refactor:

1. Read PROJECT_CONTEXT.md
2. Read FRONTEND_ARCHITECTURE.md
3. Read DEVELOPMENT_RULES.md

Then follow:

- API_STRUCTURE.md
- FLOW_ARCHITECTURE.md
- UI_DESIGN_SYSTEM.md

Goal:
Build a scalable, maintainable, enterprise-level frontend architecture.
